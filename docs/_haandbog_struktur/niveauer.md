# Håndbogsstruktur (intern note)

Denne side er en intern note om, hvordan håndbogen er tænkt struktureret.

## N1-sektioner

- **OS2-sekretariatet: Sådan arbejder vi**
- **Projekter og produkter i OS2**
- **Samarbejde i OS2-fællesskabet**
- **Værktøjskasse til projekter og produkter**

Kort mental model:

- Sekretariat = hvordan vi (sekretariatet) arbejder.
- Projekter & produkter = når læseren står med et konkret projekt/produkt.
- Samarbejde i OS2-fællesskabet = community, roller, flere med, netværk.
- Værktøjskasse = konkrete guides og skabeloner til at gøre noget nu.

Doc-sites:
- Overblik: under *Projekter og produkter i OS2* → “Dokumentation og doc-sites”.
- Værktøj: i Værktøjskassen → “Dokumentationsside til dit produkt”.
