# Samarbejde i OS2-fællesskabet <span class="label label-purple">Overblik</span> <span class="label">Fællesskab &amp; samarbejde</span>

{: .cta}
🛠️ **Leder du efter værktøjer, guides eller skabeloner?** Gå til **[Værktøjskassen](../product_toolbox)**

Her finder du information om, hvordan vi samarbejder _på tværs_ i OS2-fællesskabet. OS2-fællesskabet betegner den samlede gruppe af aktører, der er i berøring med OS2's produkter, projekter eller organisering på anden vis.

Vi forklarer, hvad vi mener med “community”, hvordan et produktfællesskab fungerer, og hvordan I kan få flere aktive med omkring en løsning – også når det føles uklart, “hvad fællesskabet egentlig er”.
