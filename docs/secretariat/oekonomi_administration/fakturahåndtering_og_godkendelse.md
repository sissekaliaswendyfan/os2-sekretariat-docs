# Fakturahåndtering og godkendelse <span class="label">Sekretariat</span>

Denne side beskriver den overordnede proces for fakturahåndtering og godkendelse i OS2.

Grundprincippet er to-trins-godkendelse: én person kontrollerer, og en anden godkender.

## Procesoverblik

1. Faktura til OS2 modtages via ITK’s system.
2. Sekretariatet kontrollerer fakturaens indhold, beløb, bilag og kontering.
3. Fakturaen sendes til korrekt godkender.
4. Godkendelsen registreres og dokumenteres.
5. Betaling håndteres af ITK’s økonomifunktion.

## Dokumentation

- Fakturaer arkiveres i ITK’s økonomisystem.
- Ved produkt- og projektspecifikke udgifter henvises til issue-ID i produktets eller projektets backlog.
- Godkendelseslisten opdateres årligt eller ved ændringer i bemanding.
