# Udbud, kontrakter og juridiske processer <span class="label">Sekretariat</span> <span class="label">Projekter &amp; produkter</span>

Denne side beskriver sekretariatets rolle i arbejdet med udbud, kontrakter og juridiske spørgsmål.

Sekretariatet understøtter produkter og projekter i kontraktmæssige spørgsmål, men OS2 udarbejder ikke selv udbudsmateriale og yder ikke juridisk rådgivning.

## Sekretariatets rolle

Sekretariatet kan hjælpe med at:

- drøfte behovet
- vurdere sammenhæng til OS2’s governance-model
- pege på relevante aktører, fx ekstern rådgiver eller kommunal jurist
- sikre, at dokumentation, licensvalg og kontraktmateriale arkiveres korrekt

## Principper

- OS2’s governance-model bruges som ramme for lovlighed, åbenhed og dokumentation.
- Open source er standard.
- OS2’s FLOSS-aftale skal medtages i relevante udviklings- og samarbejdsaftaler.
- Licensvalg og kontraktmateriale skal dokumenteres.
- Ansvar og opfølgning skal være tydeligt placeret.

## Afgrænsning

Sekretariatet yder ikke juridisk assistance.

Sekretariatet rådgiver om, at OS2’s fælles principper for open source, rettigheder og governance følges i samarbejder.
